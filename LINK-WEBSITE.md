## 📍 Bước tiếp theo: BẬT GITHUB PAGES

### Làm theo các bước sau:

1. **Mở trình duyệt** và truy cập:
   ```
   https://github.com/tranvananh152003-glitch/marketing-dashboard
   ```

2. **Click tab "Settings"** (ở menu trên cùng)

3. **Tìm "Pages"** ở menu bên trái (phần Code and automation)

4. **Tại mục "Source":**
   - Branch: Chọn **main**
   - Folder: Chọn **/ (root)**
   - Click **Save**

5. **Đợi 1-2 phút**, sau đó refresh lại trang

6. **Link website sẽ xuất hiện** ở đầu trang:
   ```
   ✅ Your site is live at https://tranvananh152003-glitch.github.io/marketing-dashboard/
   ```
